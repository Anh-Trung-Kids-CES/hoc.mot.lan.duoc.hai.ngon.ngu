🎤 Bật máy chấm AI cho trang Luyện host

Làm một lần, khoảng 5 phút, trên máy tính. Nên đăng nhập Google bằng anhtrung.home@gmail.com (tài khoản lưu dữ liệu dự án) trước khi bấm.

1
Chép code máy chấm
2
Mở dự án Apps Script mới và dán code

Bấm nút dưới, Google mở một dự án trống. Xóa đoạn code mẫu, dán code vừa chép (Ctrl+V), đặt tên dự án Máy chấm host – Chung kết, bấm biểu tượng Lưu.

Mở dự án mới
3
Thêm khóa và mã luyện

Bánh răng Cài đặt dự án ở thanh bên trái → kéo xuống Thuộc tính tập lệnh → Thêm thuộc tính tập lệnh, thêm hai dòng:

GEMINI_KEYkhóa Gemini của dự án (khóa chị vẫn dùng để thu giọng) MA_HOSTmã luyện chị tự đặt, ví dụ ck2026; host nhập mã này khi vào trang

Bấm Lưu thuộc tính tập lệnh.

4
Triển khai thành Ứng dụng web

Triển khai (góc trên bên phải) → Tùy chọn triển khai mới → bánh răng chọn loại Ứng dụng web → Thực thi với tư cách: Tôi · Ai có quyền truy cập: Bất kỳ ai → Triển khai. Google hỏi quyền: chọn tài khoản → Nâng cao → Đi tới … (không an toàn) → Cho phép (đây là script của chính chị).

Chép URL ứng dụng web (đuôi /exec).

5
